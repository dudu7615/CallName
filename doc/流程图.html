核心不变量

  • • 每人每轮恰好被点到一次（无放回）
  • • 权重 = 优先级，不是出现频率
  • • _drawn 仅内存；draw_count 才持久化
  • • draw_count 必须原子自增 draw_count + 1
  • • 先落库、再播动画：中途被杀也算数

桥接约束

  • • js_api 方法必须是普通 def（独立线程）
  • • 返回值先 model_dump(mode="json")
  • • 统一信封 ApiResponse<T>：ok / data / error
  • • 错误码稳定 ASCII，message 直接展示中文
  • • 设置窗口业务方法默认 guard=True

数据与并发

  • • 每次调用 with db.session() as s:
  • • 写操作：进程内 RLock + transaction()
  • • WAL + busy_timeout=5000 + foreign_keys=ON
  • • 主窗口与管理窗口是两个进程，共用 db
  • • 密码写入走条件 replace_admin_password

启动与路径

  • • main.py → callname.app.main()
  • • 迁移：PRAGMA user_version + MIGRATIONS
  • • Linux 钉死 gui="qt"，root 时加 no-sandbox
  • • 冻结后 BUNDLE=资源 / APP_DIR=可写
  • • --auto N 用 evaluate_js 自测
