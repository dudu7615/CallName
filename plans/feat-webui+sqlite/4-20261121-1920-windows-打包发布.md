# 移植 DesktopBackground 的 Windows 打包发布系统

日期：2026-11-21
分支：`feat/webui+sqlite`
序号：`plans/feat-webui+sqlite/4-20261121-1920-windows-打包发布.md`

## 目标

把 `/mnt/code/Code/DesktopBackground` 的「合并进 main 自动出安装包 + 按版本号建
Release」整套搬到 CallName：PyInstaller onedir → `dist/CallName/` → Inno Setup
安装包 + 便携 zip，CI 在 `windows-latest` 上跑。

## 已确认的决策

- **数据位置**：沿用便携语义，`callname.db` 继续放程序目录（exe 旁边）。
  安装包不带数据库，覆盖升级不碰、卸载也不删。代价是不像 DesktopBackground
  那样支持程序目录只读；换来「拷走整个目录就换电脑」。
- **平台**：仅 Windows。Linux 继续本地 `uv run main.py`。
- **版本**：`2.1.0`（首发 Release 为 `v2.1.0`）。
- **开机自启**：不做。点名器只在课堂上用，`[Tasks]` 只保留桌面快捷方式。

## 与 DesktopBackground 的差异

| 项 | DesktopBackground | CallName |
|---|---|---|
| 素材目录 | `clock/`（配置 + 图片） | `callname/web/`（前端 + 字体），dest 必须原样 |
| 运行期数据 | `%LOCALAPPDATA%\...\runtime\<instance>` + `.instance-key` 认领 | exe 旁边 `callname.db` / `callname.log`，不需要标记文件，卸载器不删数据 |
| 平台后端 | PySide6（托盘 + 画图） | pywebview → Windows 走 pythonnet/WebView2，需 hiddenimport |
| 安装器 `[Code]` | killapp + RemoveOwnDataIn（读标记） | 只保留 killapp，无数据认领逻辑 |
| 开机自启 | 有 | 无 |
| CI 前置 | 无测试 | `checks` job 跑 pytest + mypy |
| 产物检查 | 无 | 检查 `callname/web` 与字体，防白屏 |

## 改动

1. `pyproject.toml`：新增 `[dependency-groups] build = ["pyinstaller>=6.19"]`，
   version → `2.1.0`。
2. `.gitignore`：`!packaging/*.spec`；新增 `callname.log*`。
3. `callname/paths.py`：拆 `BUNDLE`（= `_internal/`）与 `APP_DIR`（exe 目录）；
   `ICON` 在 Windows 用 `icon.ico`；新增 `LOG_PATH`。
4. `callname/app.py`：冻结后额外挂文件日志（默认格式、1 MB × 3）；子进程 cwd 用 `APP_DIR`。
5. `packaging/main.spec`：onedir；datas `callname/web` + `icon.png/.ico`；
   `hiddenimports=["webview.platforms.winforms"]`（仅 Windows）；显式收 `_ssl`/OpenSSL，缺失时 Windows 构建失败。
6. `packaging/setup.iss`：新 AppId；装 `%LOCALAPPDATA%\CallName`；`Excludes` 运行期数据；卸载不删数据库。
7. `packaging/killapp.ps1`：按 exe 完整路径结束进程。
8. `.github/workflows/release.yml`：meta → checks → windows → publish（含产物检查、便携 zip、latest 校正）。
9. `tests/test_packaging.py`：锁住 build 组、版本号一致、spec 的 dest、
   hiddenimport、`.gitignore` 放行、三处 exe/产物名一致。
10. 文档：`packaging/README.md`、`README.md`、`CLAUDE.md`。

## 验证

- Linux 冒烟冻结构建成功；`dist/CallName/CallName --version` → `2.1.0`；

  产物里有 `_internal/callname/web/*`（含 20 MB 字体与 OFL）与两个图标
- workflow YAML 可解析，4 个 job
