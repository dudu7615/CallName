# 转盘音效：逐格 tick + 落格揭晓音 + 静音开关

## Context

现在转盘（自动模式的 CSS transition、手动停模式的 rAF 循环）全程无声。课堂上老师背对学生点击按钮时，
没有任何「正在转 / 已经停」的听觉反馈，学生也读不出转速变化。本次给转盘补两个音效：

- **tick**：每转过一个人（每跨一格）响一记，手动停模式按每 3 格抽稀（38 格/秒逐格播会糊成噪声）。
- **finish**：停稳、赢家点亮时响一次。

同时加一个主窗口的静音开关（存 `meta` 表，跨重启保持），因为同一份程序会被拷到不同教室用。

分支：`feat/reel-experience`（从 `main` 切出）；完成后按规范开 PR `V2.4.0 转盘音效 + 静音开关`。

|---|---|---|---|---|---|
| tick | `tick_001.ogg` | 23.2 ms | 44.1 kHz 单声道 | 4 497 B | 起始延迟 0 ms，频谱宽、无尾部余音，密集播放不糊 |
| finish | `confirmation_001.ogg` | 289.8 ms | 44.1 kHz 单声道 | 8 968 B | 两音上行，克制不抢戏 |

- 落库文件名：`callname/web/tick.ogg`、`callname/web/finish.ogg`（**必须平铺**，见 CLAUDE.md）。

## 实现

### 1. 音频模块 `callname/web/sfx.js`（新建）

用 **Web Audio**（`AudioContext` + `decodeAudioData` + `AudioBufferSourceNode`），不用 `HTMLAudioElement`：
tick 需要重叠播放、亚帧延迟、`playbackRate` 微抖，且不能往 DOM 里塞节点。

```js
/** @typedef {{ enabled: boolean }} SfxState */
export class Sfx {
  constructor({ tickUrl = 'tick.ogg', finishUrl = 'finish.ogg' } = {}) {}
  async unlock()   // 在用户手势调用链里 create/resume AudioContext 并预取两个 buffer
  setEnabled(on)   // 只开关播放，不影响已解码 buffer
  tick()           // 播放 tick；内部 MIN_TICK_GAP ≈ 70ms 节流，禁音/未解锁时静默 return
  finish()         // 播放 finish；内部 MIN_FINISH_GAP ≈ 250ms 防短间隔连点叠音
}
```

- 资源 URL 用 `new URL('./tick.ogg', import.meta.url)`，与 `style.css` 里字体同目录相对路径一致。
- 每个音效预建一个小池（4 个 buffer 各包一个 `AudioBufferSourceNode` 的工厂），tick 用 `playbackRate`
  在 `0.96–1.04` 间随机、增益 `0.9–1.0` 微抖，避免机械感；finish 固定速率、增益 1.0。
- 统一过一个 `GainNode`（主音量 ≈ 0.55），避免课堂音响上刺耳。
- **所有播放路径 try/catch 静默降级**：解码失败、`AudioContext` 被策略挂起、设备被拔，都只让 `tick()/finish()`
  变成空操作，绝不允许异常冒到抽签流程里。

### 2. `callname/web/reel.js`：跨格探测与回调（核心改动）

Reel 不 import 音频，改为构造时接回调，保持引擎无音频依赖：

```js
constructor(clip, strip, { onTick = null, onFinish = null } = {})
```

**自动模式**（`spin()` reel.js:91-140）——这条路径没有逐帧代码，必须自建探针：

- 在设置 transition 之后起一个 rAF 探针：每帧读 `getComputedStyle(this.strip).transform`，
  解析 `matrix(...)` 的 `m42`（注意 `strip.style.transform` 在过渡期间返回的是**目标值**，不能用）。
- `const idx = Math.floor((startY - ty) / h + 1e-6)`；`idx > this._probeIndex` 时调用 `onTick()`，
  并把 `_probeIndex` 推到 `idx`（一帧跨多格也只响一记，由 Sfx 的最小间隔兜底）。
- 在 `finish()`（reel.js:120-126，`transitionend` 与兜底 timer 都走它）里 `cancelAnimationFrame` 停探针。
- `_cancelLoop()`（reel.js:252-258）也要停探针——`kick()` / 下次 `spin()` / `startInfinite()` 都会调用它。
- `reveal()` 之后（reel.js:139）调用 `onFinish()`。
- `prefers-reduced-motion` 分支（reel.js:101-105）：不起探针、不播 tick，只在校验后调用 `onFinish()`。
- 探测频率是每帧一次 `getComputedStyle`（3 s ≈ 180 次）。若在低配教室机上观察到掉帧，退路是按
  `cubic-bezier(.08,.82,.06,1)` 反解排 10 个 `setTimeout`（位移恒为 10.04 格：`H*0.6 + h*8`，`H = 3.4h`），
  计划里不预先实现，留注释说明。

**手动停模式**（`startInfinite()` reel.js:163-198 / `_tick()` reel.js:233-241）：

- `_offset` 会对 `_periodPx` 取模归零，**不能**用它差分。新增单调累加器 `this._travel += this._speed * dt`
  （不取模），在 `_tick` 内推进。
- 跨格计数：`const crossed = Math.floor(this._travel / this._cellH) - this._cellMark`；
  `this._cellMark += crossed; this._tickAcc += crossed;`
- 每累计 3 格播一次：`while (this._tickAcc >= 3) { this._tickAcc -= 3; onTick(); }`
  （78 ms/次 ≈ 13 次/秒；`dt` 被夹到 64 ms 时最多跨 3 格，`while` 保证不丢节拍）。
- `startInfinite()` 里重置 `_travel/_cellMark/_tickAcc`；reduced-motion 分支直接 `_landNext()`，不播 tick。
- `_landNext()`（reel.js:210-230）在 `this.reveal()` 之后调用 `onFinish()`——手动落格是瞬时的，
  这里就是唯一的结束点；同时覆盖 reduced-motion 走 `_landNext` 的路径。
- `kick()`（reel.js:143-152，待机换内容）**不出声**。

### 3. `callname/web/main.js`：接线 + 解锁 + 静音按钮

- `const sfx = new Sfx();` 与 `new Reel(clip, strip, { onTick: () => sfx.tick(), onFinish: () => sfx.finish() })`。
- `doPrimary()`（main.js:247-252）开头同步调用 `void sfx.unlock();`——点击/空格是可信手势，
  `AudioContext` 必须在这里 `resume()`，不能等 `await draw()` 之后。
- `boot()`（main.js:318-332）在 `get_settings()` 之后 `sfx.setEnabled(settings.sound_enabled)` 并同步按钮态。
- 新增 `doToggleSound()`：乐观切换 + 失败回滚（照抄 `doToggleMode()` main.js:280-291 的结构），
  调用新 API `set_sound_enabled`。
- `window.__state()` 里加 `sound: sfx.enabled`，方便 `--auto` 自测与截图核对。

## 风险与已知坑

- **QtWebEngine / WebView2 的 Ogg Vorbis 解码**：两者都是 Chromium，原生支持；若某个环境 `decodeAudioData`
  失败，`unlock()` 捕获后整体静音（不崩、不阻断抽签）。兜底方案是转成 mono PCM WAV（合计约 30 KB），
  只需替换两个文件，前端无需改动。
- **自动播放策略**：音频只在 `doPrimary()` 的点击同步栈里解锁；`--auto` 的 `evaluate_js` 点击无声属预期。
- **探针开销**：每帧一次 `getComputedStyle` 会在 3 s 内做 ~180 次样式读取；只在旋转期间存在，停稳即取消。
- **窗口遮挡**：rAF 降到 1 Hz、`dt` 被夹到 64 ms，tick 会成串触发，由 Sfx 的 70 ms 间隔拦下，听感是「少响几次」。
- **resize / DPI**：`h`、`startY` 在 `spin()` 开始时实测；旋转中途 resize 本来就会让 transition 目标失效，
  本次不额外处理。
- **不把音效做成安全边界**：静音只是课堂便利，不是权限系统——文档措辞要与管理员密码那段保持一致。
