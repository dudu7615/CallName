# 转盘加速 + 手动停模式（最终实现）

> 本文件按用户要求更新为**最终实现**。早期版本想用「1–2 秒减速」，实测不符合
> 「点停就出结果」的课堂节奏，已全部删除；§3.4 记录的是最终行为。

## Context

课堂点名时，滚轮固定 4200ms 后自动停在结果上，老师无法自己控制节奏。需要：

1. **转盘转得更快**。
2. **新增「手动停」模式**（开关控制）：开启后主按钮从「开始点名」变为「开始」，
   点一下转盘开始**持续**旋转、按钮变「停」；再点一下**瞬间**停在本轮抽中的名字上。

抽中的结果仍在**第一次点击时**落库（保持 `draw.py` 的「先落库再播动画」不变量），
第二下点击只决定动画落在哪一格并点亮名字。开关状态写入 `meta`，重启后保持。

原 `reel.js` 的 `spin()` 是**一次性 CSS transition**，没有 rAF 循环，无法中途停，
因此手动停模式需要新的引擎。

## 已确认决策

| 问题 | 结论 |
| --- | --- |
| 分支 | `feat/speed-and-manual`（从 `main` 切出） |
| 模式记忆 | 写入数据库 `meta`，键 `draw_mode`，值 `auto` / `manual` |
| 抽签落库时机 | 第一下点击（与现在一致），停止只影响动画与点亮 |
| 停止方式 | **零延时**：点「停」立即落到下一格，不做补间动画 |
| 权重语义 | 不改（权重 = 优先级，无放回） |

## 1. 后端：模式持久化（已实现）

### `callname/db.py`

- `META_DRAW_MODE = "draw_mode"` 常量。
- `get_draw_mode() -> DrawMode`：手改库写成脏值时记录 warning 并回落到 `AUTO`。
- `set_draw_mode(mode: DrawMode) -> None`。
- 不需要数据库迁移（`meta` 是键值表）。

### `callname/schemas.py`

```python
class DrawMode(StrEnum):
    AUTO = "auto"       # 点一次，定长动画后自动停
    MANUAL = "manual"   # 点「开始」持续转，点「停」立即停

class SettingsResult(BaseModel):
    draw_mode: DrawMode
```

### `callname/api.py` — `MainApi`（普通 `def`，走统一信封）

- `get_settings() -> ApiResponse[SettingsResult]`
- `set_draw_mode(mode: str) -> ApiResponse[SettingsResult]`，非法值回 `BAD_MODE`。

不受管理员锁影响，也不动 `ManageApi`。

## 3. 前端：`Reel` 的持续旋转 / 瞬时停格

`build / settle / reveal / kick / _pick / _restY` 语义不变，`_restY()` 仍是唯一几何来源。

### 3.1 条带结构

```js
const MANUAL_PATTERN = 24;   // 一个周期的格数
const MANUAL_REPEATS = 4;    // 周期重复份数
const MANUAL_CELL_MS = 26;   // 匀速阶段每格耗时
```

- 条带 = 假名池循环填充 `MANUAL_PATTERN × MANUAL_REPEATS = 96` 格。
- **赢家名字不在条带里**：转动过程中全部是假名，结果不会提前泄露；
  点「停」时才把赢家名字写进落点格（`_pendingWinner`）。
- 周期像素 `periodPx = MANUAL_PATTERN * h`，`h` 必须实测。

> ⚠️ 踩过的坑：`strip.replaceChildren(frag)` 会**清空 fragment**，之后再读
> `frag.firstElementChild` 得到 `null` → 格高 0 → 周期 0 → 转盘不动。
> 必须从 `strip.firstElementChild` 取实测高度，并在 `h <= 0` 时退回直接停格。

### 3.2 接口

```js
startInfinite(decoys, winner) -> boolean   // false = reduced-motion，已直接停格点亮
stopInfinite() -> void                     // 同步、无 Promise、无动画
```

不再有 `_stopping` / `_stopPromise` / `_stopGen` 等减速期状态。

### 3.3 匀速循环

```js
_tick(ts) {
  const dt = this._lastTs ? Math.min(ts - this._lastTs, 64) : 16;  // 防遮挡时瞬移
  this._lastTs = ts;
  this._offset = (this._offset + this._speed * dt) % this._periodPx;
  this.strip.style.transform = `translate3d(0, ${-this._offset}px, 0)`;
  this._raf = requestAnimationFrame((next) => this._tick(next));
}
```

速度 `_speed = h / MANUAL_CELL_MS`（112px 格 ≈ 38.5 格/秒）。
`spin / kick / startInfinite` 入口都先 `_cancelLoop()`，避免 rAF 残留。

### 3.4 停止：瞬时落到下一格（最终行为）

```js
_landNext() {
  cancelAnimationFrame(this._raf);
  const phase = h / 2 - H / 2;                        // 让格 i 居中所需的常量项
  const raw = Math.floor((this._offset - phase) / h) + 1;   // 严格大于当前偏移的最小 i
  const index = clamp(raw, 0, cells.length - 1);
  cell.textContent = this._pendingWinner;             // 此刻才写入结果
  this._settleCell(cell);                             // transition:none + 强制 reflow
  this.reveal();                                      // 金色高亮 + pop
}
```

- 前进距离恒 **∈ (0, 1 格]**，因此「点停 → 结果出现」在同一帧完成。
- 已验证：`h ∈ {112, 86}`、`H ∈ {3.4h, 3h}` 及 125% DPI 下，
  落点恒居中、不越界（脚本遍历 offset 全程 0 失败）。
- 无补间、无 await，`stopManual()` 里也不再有异步等待。

### 3.5 减少动态

`this.reduced` 为真（或格高实测为 0）时：`startInfinite()` 直接停格点亮并返回 `false`，
主窗口按普通模式收尾，不进入「停」状态。

## 4. 前端：`main.js` 状态机与 UI

### 4.1 状态

`state` = `manual`、`spinning`、`starting`（`stopping` 已删除）。

`busy` 只表示「与后端/定长动画串行」，**手动旋转期间必须为 false**，
否则 `refreshStatus()` 会停摆、`#start` 会被禁用而无法「停」。

### 4.2 主按钮路由

```js
function nextAction() {
  if (state.busy || state.starting) return null;
  if (!state.manual) return 'draw';
  return state.spinning ? 'stop' : 'start';
}
```

点击 / `Space` / `Enter` 都走 `doPrimary()`；`startManual()` 同步置 `starting` 防双击。

### 4.3 按钮文案与禁用

| 条件 | 文案 | 禁用 |
| --- | --- | --- |
| `!manual` | 开始点名 | `busy`，或空名单 |
| `manual` 且空闲 | 开始 | `busy`，或空名单 |
| `manual` 且旋转中 | 停 | 仅 `busy`（旋转中必须可点） |

`.is-stop` 用 `var(--danger)` 渐变，和「开始」的金色区分。

### 4.4 轮询与结果保留

- 旋转期间 `refreshStatus()` 照常跑，HUD 实时更新。
- `refreshStatus({ keepResult: true })` 用于抽签后的刷新：**不要**调用 `paintIdle()`，
  否则刚点亮的赢家会被待机条带抹掉（这是实际踩到的 bug）。
- 旋转中 `changed` 分支也不得重画条带（会打断 rAF）。

### 4.5 模式开关

`index.html` 底部控制栏插入 `#mode`（`.mode-switch`，`aria-pressed` 驱动）。
文案固定为「手动停」，开/合只看高亮，避免「手动停/自动停」随状态改名导致误读。
点击乐观切换 → `api.set_draw_mode()` → 失败回滚并 toast。

### 4.6 CSS

- `.mode-switch` 写在 `main.css`，视觉沿用 `manage.css` 的 `.toggle`
  （`::before` 轨道 + `--gold` 滑点），但**不搬移** `.toggle` 本体。
- `#start` 加 `min-width` + `justify-content: center`，避免文案切换时底栏跳动。
- 不得给 `.cell` 加 padding/border（会破坏 `_restY` 的实测高度）。

## 5. `--auto` 自测入口

`app.py`：先 `clickStart`，0.7s 后 `clickStop`，再等 3.1s
（自动模式 3.0s 自停；手动模式 0.7s 旋转 + 瞬时落格）。
`clickStop` 在自动模式下是空操作。
