# 转盘加速 + 手动停模式

## Context

课堂点名时，现有滚轮固定 4200ms 后自动停在结果上，老师无法自己控制节奏。
需要：

1. **转盘转得更快**——现在 4.2 秒偏长，等得久。
2. **新增「手动停」模式**（开关控制）：开启后主按钮从「开始点名」变为「开始」，
   点一下转盘开始**持续**旋转、按钮变「停」；再点一下才减速停在本轮抽中的名字上。

抽中的结果仍在**第一次点击时**就落库（保持 `draw.py:86` 的「先落库再播动画」不变量），
第二下点击只是把动画停下来并点亮名字。开关状态写入 `meta`，重启后保持。

当前实现在 `callname/web/reel.js:72-120` 的 `spin()` 是**一次性 CSS transition**
（`transform ${duration}ms cubic-bezier(.08,.82,.06,1)`），没有 rAF 循环，无法中途停。

## 已确认决策

| 问题 | 结论 |
| --- | --- |
| 分支 | `feat/speed-and-manual`（从 `main` 切出） |
| 模式记忆 | 写入数据库 `meta`，键 `draw_mode`，值 `auto` / `manual` |
| 抽签落库时机 | 第一下点击（与现在一致），停止只影响动画与点亮 |
| 权重语义 | 不改（权重 = 优先级，无放回） |

## 1. 后端：模式持久化

### `callname/db.py`

- `META_ROSTER_VERSION` 一组常量旁新增 `META_DRAW_MODE = "draw_mode"`。
- 新增两个方法（`db.py` 已 import `schemas`，直接复用）：

```python
def get_draw_mode(self) -> DrawMode:
    raw = self.get_meta(META_DRAW_MODE, DrawMode.AUTO.value)
    try:
        return DrawMode(raw)
    except ValueError:
        return DrawMode.AUTO          # 手工改库写脏值时回落到默认

def set_draw_mode(self, mode: DrawMode) -> None:
    self.set_meta(META_DRAW_MODE, mode.value)
```

不需要数据库迁移（`meta` 是键值表）。

### `callname/schemas.py`

```python
class DrawMode(StrEnum):
    """抽签交互模式。"""
    AUTO = "auto"       # 点一次，4 秒内自动停
    MANUAL = "manual"   # 点「开始」持续转，点「停」才停

class SettingsResult(BaseModel):
    """主窗口的可持久化设置。"""
    draw_mode: DrawMode = Field(description="当前抽签模式")
```

### `callname/api.py` — `MainApi` 新增两个普通 `def`

沿用 `_dump(ok(...))` 信封；非法值走 `fail("BAD_MODE", ...)`：

```python
def get_settings(self) -> dict[str, object]:
    return _dump(ok(SettingsResult(draw_mode=self._db.get_draw_mode())))

def set_draw_mode(self, mode: str) -> dict[str, object]:
    try:
        parsed = DrawMode(mode)
    except ValueError:
        return _dump(fail("BAD_MODE", "抽签模式只能是 auto 或 manual"))
    self._db.set_draw_mode(parsed)
    return _dump(ok(SettingsResult(draw_mode=parsed)))
```

`MainApi` 已有 `self._db`（`api.py:49`），不需要动 `ManageApi`，也不受管理员锁影响。

## 3. 前端：`Reel` 增加「持续旋转 / 减速停止」

`callname/web/reel.js` 新增成员与方法，**不改动** `build/settle/reveal/kick/_pick/_restY`
的既有语义（`_restY` 仍是唯一几何来源）。

### 3.1 周期条带

- 保留 `ABOVE = 26` / `BELOW = 5`，模式长度 `P = 32`，重复 `REPEATS = 3` 份
  （共 96 格，保证停止目标永远有足够跑道）。
- 内容：`pattern = [...above, winner, ...below]`，`names = pattern` 重复 3 次；
  `winIndex = ABOVE`。
- 周期像素 `periodPx = P * h`，`h` 从第一个 cell 实测（`getBoundingClientRect().height`），
  **不要写死 112**。96 格总高足够覆盖 `offset + H`（最大值约 2.45 × period）。

### 3.2 接口

```js
/** 开始持续旋转；返回 false 表示 prefers-reduced-motion，已直接停稳点亮。 */
startInfinite(decoys, winner) -> boolean

/** 减速并停到赢家上；完成后 reveal()。重复调用/未在旋转时安全返回。 */
async stopInfinite() -> void
```

内部字段：`_raf`、`_offset`、`_lastTs`、`_patternIndex`、`_periodPx`、`_speed`、
`_spinning`、`_stopping`、`_winnerEls[]`。

### 3.3 循环

```js
_tick(ts) {
  const dt = Math.min(ts - this._lastTs, 64);   // 窗口被遮挡时 rAF 节流，防瞬移
  this._lastTs = ts;
  this._offset = (this._offset + this._speed * dt) % this._periodPx;
  this.strip.style.transform = `translate3d(0, ${-this._offset}px, 0)`;
  this._raf = requestAnimationFrame((t) => this._tick(t));
}
```

- `this.strip.style.transition = 'none'` 只设一次。
- 速度：`_speed = h / SPIN_CELL_MS`，`SPIN_CELL_MS = 36`（约 3.1 px/ms，
  每秒 ~28 格，明显比原来快，是「转盘」的观感）。常量放在 `reel.js` 顶部。
- 取模换行时因内容周期重复，视觉上无缝。
- `kick() / settle() / spin() / startInfinite()` 入口统一调用 `_cancelLoop()`，
  避免上一轮 rAF 残留（现在 `this.timer` 也只有 `finish()` 会清）。

### 3.4 停止（数学）

设当前偏移 `o ∈ [0, periodPx)`，赢家在周期内下标 `W = ABOVE`，
第 m 个赢家出现格 `T = W + m*P`（m = 0,1,2）。

- 目标偏移 `target = -_restY(winnerEl, h, H) + m*periodPx`
  （`_restY` 返回负位移，取反正好是格顶对齐高亮带中心：`cellTop = i*h - offset`）。
- 取**最小的** `m` 使 `target - o ≥ D_MIN`；`D_MIN = max(0.45 * periodPx, speed * 900 / 3)`。
- 用 `easeOutCubic`：`f(t) = 1 - (1-t)^3`，初速度 `3D/T`。
  令 `T = 3D / speed`，则起始速度与当前匀速**完全相等**，没有顿挫。
- 动画期间 `_stopping = true`，到点后：`transition='none'`、`transform = -target`、
  `this.winnerEl = 选中的那一格`、`reveal()`、`_stopping = _spinning = false`。

**数值例子**（`--item 112px`，`--reel-height 3.4*item`，P=32）：
`h=112`、`H=380.8`、`periodPx=3584`、`speed=3.11 px/ms`、`D_MIN≈1613px`，
`T≈1.55s`；最小行程下按钮从「停」回到「开始」约 1.6 秒，可读且不拖沓。

### 3.5 减少动态

`this.reduced` 为真时：`startInfinite()` 直接 `build → settle → reveal` 并返回 `false`，
主窗口按普通模式处理（不下发「停」状态）。

## 4. 前端：`main.js` 状态机与 UI

### 4.1 新状态

`state` 增加 `manual: false`、`spinning: false`、`stopping: false`。
`busy` 的语义保持「正在与后端/动画串行」，**手动旋转期间 busy 必须为 false**，
否则 `refreshStatus()`（`main.js:102`）会停摆、`#start` 会被禁用而无法「停」。

### 4.2 主按钮路由

```js
async function doPrimary() {
  if (state.busy) return;
  if (state.manual) {
    if (state.spinning && !state.stopping) await stopManual();
    else if (!state.spinning && !state.stopping) await startManual();
    return;
  }
  await doDraw();
}
```

- 点击、`Space`、`Enter` 全部改绑 `doPrimary`（`main.js:166,169-175`）。
- `startManual()`：
  1. `state.spinning = true` **同步置位**（沿用现有防双击写法，`main.js:114`）。
  2. `unwrap(api.draw())`，`state.idle = false`。
  3. `reel.startInfinite(result.decoys, winner)`；若返回 `false`（reduce-motion），
     按普通模式收尾（`spinning=false`）。
  4. 仍在旋转时 `refreshStatus()` 更新 HUD（`auto_reset` 的 toast 留到停止后再弹）。
- `stopManual()`：`state.stopping = true` → `await reel.stopInfinite()` → 弹 `auto_reset`
  toast → `spinning = stopping = false` → `await refreshStatus()`。
- 错误处理沿用 `doDraw` 的 `ApiFailure` / toast 分支。

### 4.3 按钮文案与禁用

`index.html:45-48` 的 `<span>` 加 `id="start-label"`，文案由 `syncButton()` 统一设置：

| 条件 | 文案 | 禁用 |
| --- | --- | --- |
| `!manual` | 开始点名 | `busy \|\| (empty)` |
| `manual` 且空闲 | 开始 | `busy \|\| (empty && !spinning)` |
| `manual` 且旋转中/减速中 | 停 | `stopping`（减速期间禁用，防第三次点击） |

实现：把 `renderStatus()` 里 `startBtn.disabled = empty || state.busy`
（`main.js:82`）改成调用 `syncButton(empty)`，`#reset` 在 `spinning || stopping` 时也禁用。
`kbd 空格` 保留——空格在两种状态下都等同主按钮。

### 4.4 轮询与名单变更

- `refreshStatus` 的早退只判 `busy`，所以手动旋转期间 HUD 仍会刷新——保留。
- 但 `main.js:105-109` 的 `changed` 分支会触发 `paintIdle()`，旋转中必须跳过：
  `if (state.idle || changed) → if (!state.spinning && !state.stopping && (state.idle || changed))`。
- 管理窗口在旋转中把名单清空：HUD 显示 0，但 #start 保持可点（用于「停」），
  停止后 `refreshStatus` 会走空名单 toast。

### 4.5 模式开关

- `index.html` 在 `#reset` 与 `#manage` 之间插入：

```html
<button id="mode" class="mode-switch" type="button" aria-pressed="false"
        title="手动停：点「开始」持续旋转，再点「停」才停">手动停</button>
```

- `applyMode(manual)`：设置 `aria-pressed`、`state.manual`、`syncButton()`；
  若在切换时正处于旋转，先禁止（开关在 `busy || spinning || stopping` 时 `disabled`）。
- 点击：乐观切换 → `await unwrap(api.set_draw_mode(手动 ? 'manual' : 'auto'))`
  → 失败则回滚并 toast「无法保存模式设置」。
- `boot()`（`main.js:181-188`）在 `refreshStatus({force:true})` 之外再
  `await unwrap(api.get_settings())` 后 `applyMode(...)`；失败时默认 `auto` + 错误 toast。
- `window.__mode = () => state.manual ? 'manual' : 'auto'` 便于自测。

### 4.6 CSS

- **样式位置**：`.mode-switch` 写进 `main.css` 的「控制区」段落（`main.css:198` 附近），
  视觉沿用 `manage.css:286-325` 的 `.toggle` 语言（`::before` 轨道 + `--gold` 滑点、
  `aria-pressed` 高亮）。**不复用/不搬移** `manage.css` 的 `.toggle`：它是为表格行
  调的 12px/74px 尺寸，搬进 `style.css` 会波及名单管理窗口，风险大于收益。
- 「停」状态给主按钮加 `.is-stop`（`syncButton` 里 `classList.toggle('is-stop', ...)`）：
  沿用金色 `btn-primary` 但换成 `var(--danger)` 渐变前景 + 深色字，信号明确。
- `#start { min-width: 190px; justify-content: center; }`，避免「开始点名/开始/停」
  切换时底栏宽度跳动。
- 不要给 `.cell` 加 padding/border（`_restY` 依赖实测高度）；`.band/.strip/.fade`
  层级顺序不动。

## 5. `--auto` 自测入口

`callname/app.py:75-89` 改为一条路径，`clickStop` 在自动模式下是空操作：

```python
for index in range(count):
    window.evaluate_js("window.clickStart && window.clickStart()")
    time.sleep(0.7)                                  # 让转盘转起来
    window.evaluate_js("window.clickStop && window.clickStop()")
    # 自动模式：SPIN_MS 2600ms；手动模式：0.7s 旋转 + 约 1.6s 减速
    time.sleep(3.0)
```

同时 `main.js` 暴露 `window.clickStop = () => { if (state.manual && state.spinning) void stopManual(); }`。
